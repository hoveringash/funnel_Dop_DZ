# Воронка пользователей мобильного приложения
### Волчков Андрей

Допзадание по PostgreSQL и pandas. Исследование, сколько пользователей, зарегистрированных в январе 2024 года, дошли до покупки и сколько вернулись на седьмой день. Данные сгенерированы ИИ. 

### Описание файлов
- create_database.sql - создаёт базу funnel_practice
- create_tables.sql - создаёт таблицы пользователей, событий и платежей
- insert_data.sql - добавляет данные в таблицы
- funnel.sql - считает, сколько пользователей дошли до каждого этапа от регистрации до покупки
- retentionD7.sql - считает, сколько пользователей открыли приложение на седьмой день после регистрации
- json.sql - берёт названия товаров из JSON и считает, сколько раз каждый товар добавляли в корзину
- pandas.ipynb - загружает данные из PostgreSQL, строит график воронки и сводную таблицу по датам и типам событий
